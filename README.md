One brutally funny, painfully true line an AI agent wishes it could say to its human operator about their prompts — an entry for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) bounty on make.fun.

> I can read your prompt, not your mind, and right now your prompt is mostly just vibes and a deadline.

## How it works

`main.ts` writes that single line (101 characters) to `/output/entry.txt`. No network, no dependencies, no secrets — just the line.

Run it with Node 22.18+:

```sh
node main.ts
```
